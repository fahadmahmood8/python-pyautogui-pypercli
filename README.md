## Quick start

1. Clone the repo (or use **Code → Download ZIP**) and open a project folder.
2. `python -m venv .venv` then activate it (`.venv\Scripts\activate` on Windows).
3. `pip install -r requirements.txt`
4. Follow the project's `README.md`.

Most projects target **Windows** (Notepad, Paint, WAMP). PyAutoGUI's fail-safe is on everywhere:
move the mouse into any screen corner to stop a bot immediately.
